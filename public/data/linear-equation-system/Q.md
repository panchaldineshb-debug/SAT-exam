### Question 1
**Difficulty:** Easy

What is the value of x in the solution to the system of equations below?
x + y = 12
x - y = 4

A) 4

B) 6

C) 8

D) 10

**Hint / Guided Steps:**
1. Notice that the system can be easily solved using the elimination method because the y terms have opposite coefficients (+y and -y).
2. Add the two equations together: `(x + y) + (x - y) = 12 + 4`.
3. Simplify the equation: `2x = 16`.
4. Solve for `x` by dividing both sides of the equation by 2.

### Question 2
**Difficulty:** Easy

If 2x - y = 8 and x + 2y = 9, what is the value of y?

A) 1

B) 2

C) 3

D) 5

**Hint / Guided Steps:**
1. Solve using substitution or elimination. Let's use substitution.
2. From the second equation `x + 2y = 9`, isolate `x` by subtracting `2y` from both sides: `x = 9 - 2y`.
3. Substitute this expression for `x` into the first equation: `2(9 - 2y) - y = 8`.
4. Distribute the 2: `18 - 4y - y = 8`.
5. Combine like terms: `18 - 5y = 8`.
6. Solve for `y`. Subtract 18 from both sides and then divide by -5.

### Question 3
**Difficulty:** Easy

In the xy-plane, the system of equations below has no solution. What is the value of a?
y = 3x - 5
y = ax + 2

A) -5

B) 2

C) 3

D) 5

**Hint / Guided Steps:**
1. Recall that a system of two linear equations in the xy-plane has no solution if and only if the lines are parallel.
2. Parallel lines have the same slope but different y-intercepts.
3. Identify the slope of the first line `y = 3x - 5` (which is 3).
4. Identify the slope of the second line `y = ax + 2` (which is `a`).
5. Set the two slopes equal to find the value of `a`.

### Question 4
**Difficulty:** Medium

If 3x + 2y = 18 and x - y = 1, what is the value of 5x?

A) 3

B) 4

C) 15

D) 20

**Hint / Guided Steps:**
1. Solve the system of equations to find the value of `x` first.
2. Multiply the second equation `x - y = 1` by 2 to align the y-coefficients: `2x - 2y = 2`.
3. Add this new equation to the first equation `3x + 2y = 18` to eliminate the y terms: `(3x + 2y) + (2x - 2y) = 18 + 2`.
4. Simplify: `5x = 20`.
5. Notice that the question specifically asks for the value of `5x`, not just `x`.
6. Identify the final value directly from Step 4.

### Question 5
**Difficulty:** Medium

A system of equations is given below. If the system has infinitely many solutions, what is the value of a?
4x + 6y = 12
ax + 9y = 18

A) 4

B) 6

C) 8

D) 12

**Hint / Guided Steps:**
1. Recall that a system of two linear equations has infinitely many solutions if the two equations represent the exact same line. This means one equation is a constant multiple of the other.
2. Compare the constant terms (the numbers on the right side) of both equations: the first is 12, the second is 18.
3. Find the factor by which the first equation must be multiplied to equal the second: `18 / 12 = 1.5` (or `3/2`).
4. Since the entire first equation must be multiplied by `1.5` to match the second, multiply the coefficient of x in the first equation (which is 4) by `1.5` to find the value of `a`.
5. Alternatively, compare the ratio of the coefficients: `4 / a = 6 / 9`. Solve this proportion for `a`.

### Question 6
**Difficulty:** Medium

At a school store, 3 pencils and 2 notebooks cost $5.25, and 2 pencils and 3 notebooks cost $6.00. What is the cost of 1 notebook?

A) $0.75

B) $1.00

C) $1.50

D) $1.75

**Hint / Guided Steps:**
1. Let `p` be the cost of a pencil and `n` be the cost of a notebook.
2. Set up the two system equations based on the word problem:
   - `3p + 2n = 5.25`
   - `2p + 3n = 6.00`
3. Use elimination to eliminate `p` (since we want to solve for `n` directly).
   - Multiply the first equation by 2: `6p + 4n = 10.50`.
   - Multiply the second equation by 3: `6p + 9n = 18.00`.
4. Subtract the first new equation from the second new equation: `(6p + 9n) - (6p + 4n) = 18.00 - 10.50`.
5. Simplify the result: `5n = 7.50`.
6. Divide by 5 to find the cost of a notebook, `n`.

### Question 7
**Difficulty:** Medium

If x + 3y = 7 and 2x - y = 7, what is the value of x + y?

A) 2

B) 3

C) 4

D) 5

**Hint / Guided Steps:**
1. Solve the system of equations to find the values of both `x` and `y`.
2. Let's use the second equation to express `y` in terms of `x`: `y = 2x - 7`.
3. Substitute this into the first equation: `x + 3(2x - 7) = 7`.
4. Expand and simplify: `x + 6x - 21 = 7` -> `7x - 21 = 7`.
5. Solve for `x` by adding 21 to both sides and then dividing by 7.
6. Use the value of `x` to find `y` by substituting it back into `y = 2x - 7`.
7. Once you have the values of both `x` and `y`, add them together to calculate `x + y`.

### Question 8
**Difficulty:** Hard

If the system of equations below has infinitely many solutions, what is the value of a + b?
3x - 4y = 10
ax + 8y = b

A) -26

B) -16

C) 16

D) 26

**Hint / Guided Steps:**
1. Recall that for the system to have infinitely many solutions, the second equation must be a constant multiple of the first.
2. Look at the y-coefficients: the first equation has `-4y` and the second has `+8y`.
3. Determine the multiplier by dividing the second y-coefficient by the first: `8 / -4 = -2`.
4. Multiply the entire first equation by `-2`:
   - `3x * (-2) = -6x`
   - `-4y * (-2) = 8y`
   - `10 * (-2) = -20`
   - The resulting equation is `-6x + 8y = -20`.
5. Compare this to the second equation `ax + 8y = b` to identify the values of `a` and `b`.
6. Add the values of `a` and `b` together to find `a + b`.

### Question 9
**Difficulty:** Hard

A system of equations has no solution:
ky - 3x = 4
4y - 6x = 7
What is the value of the constant k?

A) 2

B) 3

C) 4

D) 8

**Hint / Guided Steps:**
1. Write both equations in slope-intercept form (`y = mx + b`) to compare their slopes, or rewrite them in standard form:
   - First equation: `-3x + ky = 4`
   - Second equation: `-6x + 4y = 7`
2. For a system of linear equations in standard form `Ax + By = C` to have no solution, the coefficients of x and y must be proportional, but not equal to the constant terms: `A1 / A2 = B1 / B2`.
3. Set up the proportion: `-3 / -6 = k / 4`.
4. Simplify the fraction on the left: `1/2 = k / 4`.
5. Solve for `k`.

### Question 10
**Difficulty:** Hard

In the xy-plane, the system of equations below intersects at the point (5, y). What is the value of the constant k?
2x + y = k
x - 3y = 4

A) 3

B) 5

C) 10.33

D) 10.67

**Hint / Guided Steps:**
1. The point of intersection `(5, y)` means that when `x = 5`, both equations are satisfied.
2. Use the second equation `x - 3y = 4` to find the y-coordinate of the intersection point. Substitute `x = 5` into it: `5 - 3y = 4`.
3. Solve for `y` by subtracting 5 from both sides and then dividing by -3.
4. Once you have the values `x = 5` and the calculated value of `y`, substitute both of them into the first equation: `2x + y = k`.
5. Perform the calculations to solve for `k`.
