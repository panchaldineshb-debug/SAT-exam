### Question 1
**Difficulty:** Easy

What is the value of x in the solution to the system of equations below?
3x/2 + y = 7
x - y/2 = 1

A) 1

B) 2

C) 3

D) 4

**Hint / Guided Steps:**
1. Eliminate the fractions by multiplying the equations by their denominators:
   - Multiply the first equation by 2: `3x + 2y = 14`.
   - Multiply the second equation by 2: `2x - y = 2`.
2. Now solve the system of equations:
   - Multiply the second new equation `2x - y = 2` by 2 to align the y terms: `4x - 2y = 4`.
3. Add the first equation `3x + 2y = 14` and the updated second equation `4x - 2y = 4` to eliminate `y`.
4. Solve the resulting equation for `x`.

### Question 2
**Difficulty:** Easy

In the xy-plane, the graphs of the linear equations y = 2x + 3 and y = -x - 6 intersect at a point. In which quadrant of the coordinate plane does the intersection point lie?

A) Quadrant I

B) Quadrant II

C) Quadrant III

D) Quadrant IV

**Hint / Guided Steps:**
1. Find the coordinates of the intersection point `(x, y)` by setting the two equations equal to each other: `2x + 3 = -x - 6`.
2. Solve this equation for `x`. Add `x` to both sides and subtract 3 from both sides.
3. Once you have `x`, substitute it back into either equation to calculate the corresponding `y` value.
4. Review the signs of the coordinates `(x, y)`:
   - Quadrant I: `(+, +)`
   - Quadrant II: `(-, +)`
   - Quadrant III: `(-, -)`
   - Quadrant IV: `(+, -)`
5. Match the signs of your intersection point to determine the quadrant.

### Question 4
**Difficulty:** Medium

A system of equations is given below. If the system has no solution, what is the value of the constant a?
ax + 3y = 5
2x + 6y = 7

A) 1

B) 2

C) 3

D) 4

**Hint / Guided Steps:**
1. Recall that a system of two linear equations has no solution if the lines are parallel. This means the slopes are equal, but the y-intercepts are different.
2. Write both equations in slope-intercept form (`y = mx + b`):
   - First equation: `3y = -ax + 5` -> `y = -(a/3)x + 5/3`. Slope is `-a/3`.
   - Second equation: `6y = -2x + 7` -> `y = -(2/6)x + 7/6` -> `y = -(1/3)x + 7/6`. Slope is `-1/3`.
3. Set the slopes equal to each other: `-a/3 = -1/3`.
4. Solve for `a`.

### Question 5
**Difficulty:** Medium

In the system of equations below, what is the value of z?
x + y + z = 12
x - y = 2
y + z = 8

A) 2

B) 4

C) 6

D) 8

**Hint / Guided Steps:**
1. Notice that the third equation gives the sum of two variables directly: `y + z = 8`.
2. Substitute the expression `y + z = 8` into the first equation `x + (y + z) = 12`: `x + 8 = 12`.
3. Solve for `x`.
4. Use the second equation `x - y = 2` and the value of `x` you just found to solve for `y`.
5. Once you have `y`, substitute it into the third equation `y + z = 8` to find the value of `z`.

### Question 6
**Difficulty:** Medium

A chemist wants to mix a solution that is 20% acid by volume with a solution that is 50% acid by volume to obtain 10 liters of a solution that is 38% acid by volume. How many liters of the 50% acid solution are needed?

A) 4

B) 6

C) 8

D) 10

**Hint / Guided Steps:**
1. Let `x` be the volume (in liters) of the 20% solution, and `y` be the volume of the 50% solution.
2. Set up the first equation representing the total volume of the mixture: `x + y = 10`.
3. Set up the second equation representing the total volume of pure acid: `0.20x + 0.50y = 0.38 * 10` -> `0.20x + 0.50y = 3.8`.
4. Solve the system of equations. From the first equation, write `x = 10 - y`.
5. Substitute this into the second equation: `0.20(10 - y) + 0.50y = 3.8`.
6. Expand and simplify: `2 - 0.20y + 0.50y = 3.8` -> `2 + 0.30y = 3.8`.
7. Solve for `y` (the volume of the 50% acid solution).

### Question 7
**Difficulty:** Medium

If 3x - 5y = 11 and 2x + 3y = 1, what is the value of x - y?

A) -2

B) -1

C) 1

D) 3

**Hint / Guided Steps:**
1. Solve the system of equations to find the values of `x` and `y`.
2. Use the elimination method:
   - Multiply the first equation by 3: `9x - 15y = 33`.
   - Multiply the second equation by 5: `10x + 15y = 5`.
3. Add the two new equations together to eliminate the y terms: `19x = 38`.
4. Solve for `x`.
5. Substitute this value of `x` back into either original equation to find `y`.
6. Once you have both `x` and `y`, calculate the value of `x - y`.

### Question 8
**Difficulty:** Hard

For what value of the constant k will the system of equations below have no solution?
2x - 3y = 5
kx - 4y = 6

A) 8/3

B) 3

C) 4

D) 6

**Hint / Guided Steps:**
1. Recall that the system `A1x + B1y = C1` and `A2x + B2y = C2` has no solution if the ratio of the coefficients of x and y are equal, but not equal to the ratio of the constants: `A1 / A2 = B1 / B2`.
2. Identify the coefficients:
   - `A1 = 2`, `B1 = -3`
   - `A2 = k`, `B2 = -4`
3. Set up the proportion: `2 / k = -3 / -4`.
4. Simplify the right side: `2 / k = 3 / 4`.
5. Solve for `k` by cross-multiplying: `3k = 8`.

### Question 9
**Difficulty:** Hard

If the graphs of the linear equations ax + by = c and dx + ey = f are perpendicular in the xy-plane, which of the following relationships must be true about their coefficients? (Assume b and e are not 0).

A) ad + be = 0

B) ae - bd = 0

C) ad - be = 0

D) ae + bd = 0

**Hint / Guided Steps:**
1. Find the slope of each line by writing them in slope-intercept form:
   - First line: `by = -ax + c` -> `y = -(a/b)x + c/b`. Slope `m1 = -a/b`.
   - Second line: `ey = -dx + f` -> `y = -(d/e)x + f/e`. Slope `m2 = -d/e`.
2. Recall that perpendicular lines have slopes that multiply to -1: `m1 * m2 = -1`.
3. Substitute the slopes into the equation: `(-a/b) * (-d/e) = -1`.
4. Simplify the multiplication: `(ad) / (be) = -1`.
5. Multiply both sides by `be`: `ad = -be`.
6. Move all terms to one side of the equation to find the matching option.

### Question 10
**Difficulty:** Hard

A system of equations 2x + 5y = 8 and 4x + ky = 16 has infinitely many solutions. If a third line y = mx + 2 passes through the intersection of the first two lines, what is the value of the constant m?

A) -1/2

B) -1/5

C) 1/5

D) 1/2

**Hint / Guided Steps:**
1. Find the value of `k` first. Since there are infinitely many solutions, the second equation is a multiple of the first. Multiply the first equation by 2: `4x + 10y = 16`. Comparing this to the second equation shows `k = 10`.
2. Since the first two lines are identical, their intersection is any point lying on the line `2x + 5y = 8`.
3. Find a convenient point on this line by setting one coordinate to 0. For example, if `y = 0`, then `2x = 8` -> `x = 4`. So the point is `(4, 0)`.
4. Since the third line `y = mx + 2` passes through this intersection point, substitute the coordinates `(4, 0)` into it: `0 = m(4) + 2`.
5. Solve this equation for `m`.
