### Question 1
**Difficulty:** Easy

In right triangle ABC, the length of the hypotenuse AC is 10 and the length of the side opposite angle A is BC = 6. What is the value of sin(A)?

A) 3/5

B) 4/5

C) 3/4

D) 5/3

**Hint / Guided Steps:**
1. Recall the definition of the sine ratio in a right triangle: `sin(A) = Opposite / Hypotenuse`.
2. Identify the side opposite angle A (which is BC = 6).
3. Identify the hypotenuse (which is AC = 10).
4. Set up the fraction: `6 / 10`.
5. Simplify the fraction by dividing the numerator and denominator by 2.

### Question 2
**Difficulty:** Easy

In right triangle PQR, the lengths of the legs are PQ = 3 and QR = 4. If the leg of length 3 is adjacent to angle P, what is the value of tan(P)?

A) 3/4

B) 4/3

C) 3/5

D) 4/5

**Hint / Guided Steps:**
1. Recall the definition of the tangent ratio in a right triangle: `tan(P) = Opposite / Adjacent`.
2. Identify the side adjacent to angle P (which is PQ = 3).
3. Identify the side opposite to angle P (which is QR = 4).
4. Set up the fraction: `Opposite / Adjacent = 4 / 3`.

### Question 3
**Difficulty:** Easy

What is the exact value of cos(60 degrees)?

A) 1/2

B) \sqrt{2}/2

C) \sqrt{3}/2

D) 1

**Hint / Guided Steps:**
1. Recall the values of special angles from a 30-60-90 special right triangle:
   - In a 30-60-90 triangle, if the hypotenuse is 2, the side opposite 30 degrees is 1, and the side opposite 60 degrees is `\sqrt{3}`.
2. The angle opposite the adjacent side of 60 degrees is the 30-degree side (which has length 1).
3. Use the definition: `cos(60) = Adjacent / Hypotenuse`.
4. Substitute the side lengths: `1 / 2`.

### Question 4
**Difficulty:** Medium

In a right triangle, one of the acute angles is \theta. If tan(\theta) = 5/12, what is the value of cos(\theta)?

A) 5/13

B) 12/13

C) 13/12

D) 12/5

**Hint / Guided Steps:**
1. Recall the tangent definition: `tan(\theta) = Opposite / Adjacent = 5 / 12`. Let the opposite side be 5 and the adjacent side be 12.
2. Find the length of the hypotenuse using the Pythagorean theorem: `Hypotenuse^2 = Opposite^2 + Adjacent^2`.
3. Substitute the values: `Hypotenuse^2 = 5^2 + 12^2 = 25 + 144 = 169`. Take the square root of 169 to find the hypotenuse.
4. Recall the cosine definition: `cos(\theta) = Adjacent / Hypotenuse`.
5. Substitute the adjacent side (12) and the hypotenuse you calculated into the fraction.

### Question 5
**Difficulty:** Medium

In right triangle XYZ, the hypotenuse is XZ = 12. If the measure of angle X is 30 degrees, what is the length of side YZ (the side opposite to angle X)?

A) 6

B) 6\sqrt{2}

C) 6\sqrt{3}

D) 12

**Hint / Guided Steps:**
1. Recall the properties of a 30-60-90 special right triangle: the side opposite the 30-degree angle is always half the length of the hypotenuse.
2. Alternatively, use trigonometry: `sin(30 degrees) = Opposite / Hypotenuse` -> `sin(30) = YZ / XZ`.
3. Substitute the known values: `sin(30) = 0.5` and `XZ = 12`.
4. Solve for `YZ`: `YZ = 12 * 0.5`.

### Question 7
**Difficulty:** Medium

In the xy-plane, the terminal side of an angle \theta in standard position passes through the point (3, 4). What is the value of sin(\theta)?

A) 3/5

B) 4/5

C) 3/4

D) 4/3

**Hint / Guided Steps:**
1. Plot the point `(3, 4)` conceptually. This forms a right triangle with the x-axis, where the adjacent side `x = 3` and the opposite side `y = 4`.
2. Find the distance from the origin `(0, 0)` to the point `(3, 4)` using the distance formula (which is the hypotenuse `r`): `r = \sqrt{3^2 + 4^2} = 5`.
3. Recall the coordinate definitions of trigonometric functions: `sin(\theta) = y / r`.
4. Substitute the values of `y = 4` and `r = 5` into the fraction.

### Question 8
**Difficulty:** Hard

In right triangle ABC, the measure of angle C is 90 degrees. If tan(A) = 3/4, what is the value of sin(A) + cos(A)?

A) 7/12

B) 1

C) 7/5

D) 12/5

**Hint / Guided Steps:**
1. From `tan(A) = 3/4 = Opposite / Adjacent`, let the side opposite angle A be 3 and the side adjacent to angle A be 4.
2. Find the hypotenuse using the Pythagorean theorem: `3^2 + 4^2 = c^2` -> `c = 5` (a 3-4-5 right triangle).
3. Find the value of `sin(A) = Opposite / Hypotenuse = 3 / 5`.
4. Find the value of `cos(A) = Adjacent / Hypotenuse = 4 / 5`.
5. Add the two fractions together: `3/5 + 4/5`.

### Question 9
**Difficulty:** Hard

A ladder leaning against a vertical wall makes an angle of 60 degrees with the flat ground. If the base of the ladder is placed exactly 5 feet away from the wall, how long, in feet, is the ladder?

A) 5\sqrt{3}

B) 10

C) 10\sqrt{3}

D) 20

**Hint / Guided Steps:**
1. Visualize the scenario as a right triangle:
   - The ladder is the hypotenuse `H`.
   - The ground distance between the wall and the ladder is the adjacent side to the 60-degree angle, which has length 5.
2. Use the trigonometric ratio that relates the adjacent side to the hypotenuse: `cos(60 degrees) = Adjacent / Hypotenuse`.
3. Substitute the known values: `cos(60) = 0.5` and `Adjacent = 5`.
4. Set up the equation: `0.5 = 5 / H`.
5. Solve for `H` (the length of the ladder).

### Question 10
**Difficulty:** Hard

If sin(\theta) = 2/3 and \theta is an acute angle, what is the value of tan(\theta)?

A) 2/\sqrt{5}

B) \sqrt{5}/3

C) 3/2

D) \sqrt{5}/2

**Hint / Guided Steps:**
1. Let `sin(\theta) = 2/3 = Opposite / Hypotenuse`. Represent this on a right triangle where the opposite side is 2 and the hypotenuse is 3.
2. Use the Pythagorean theorem to find the adjacent side `x`: `x^2 + 2^2 = 3^2` -> `x^2 + 4 = 9` -> `x^2 = 5`. Solve for `x`.
3. Recall the tangent definition: `tan(\theta) = Opposite / Adjacent`.
4. Substitute the opposite side (2) and the adjacent side you calculated into the fraction.
