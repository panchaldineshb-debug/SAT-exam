# SAT Prep: Graphs - Practice Questions (Q.md)

This file contains 10 practice questions on Graphs for the SAT. Each question includes a multiple-choice layout followed by hints and guided steps — **no answers are given**. Work through the hints to find the solution yourself, Student!

### Question 1
**Difficulty:** Easy

A line in the xy-plane passes through the points (0, 3) and (2, 7). Which of the following is the equation of the line?

A) y = 2x + 3

B) y = 3x + 2

C) y = 4x + 3

D) y = 2x + 7

**Hint / Guided Steps:**
1. Determine the slope `m` of the line using the two points: `(7 - 3) / (2 - 0)`.
2. Notice that one of the points is `(0, 3)`. Since `x = 0`, this gives the y-intercept of the line directly, which is `b = 3`.
3. Put the slope and y-intercept into the slope-intercept equation: `y = mx + b`.

### Question 2
**Difficulty:** Easy

The graph of a quadratic function in the xy-plane is a parabola with its vertex at the point (2, -5). What is the minimum value of this function?

A) -5

B) -2

C) 2

D) 5

**Hint / Guided Steps:**
1. Recall that the vertex of a parabola `(h, k)` represents the highest (maximum) or lowest (minimum) point on the graph.
2. Since the parabola opens upward (default unless stated otherwise), the minimum value of the function is the y-coordinate of the vertex.
3. Identify the y-coordinate of the vertex `(2, -5)`.

### Question 3
**Difficulty:** Easy

A graph shows the linear relationship between the temperature, T, in degrees Fahrenheit, of an oven and the time, m, in minutes, since it was turned on. The line passes through the points (0, 60) and (4, 72). What does the T-intercept (the vertical intercept) of the graph represent in this context?

A) The temperature of the oven increases by 60 degrees every minute.

B) The initial temperature of the oven is 60 degrees Fahrenheit.

C) It takes 60 minutes for the oven to reach its maximum temperature.

D) The temperature of the oven increases by 12 degrees every minute.

**Hint / Guided Steps:**
1. Understand that the vertical intercept (T-intercept) occurs where the horizontal variable (time, `m`) equals 0.
2. Identify the coordinates of the vertical intercept from the points given: `(0, 60)`.
3. Interpret what `m = 0` minutes means in the context of the scenario (the start of the process).
4. Match this interpretation of the starting temperature to the options.

### Question 4
**Difficulty:** Medium

The graph of the exponential function y = a * b^x, where a and b are constants, passes through the points (0, 5) and (1, 15). What is the value of b?

A) 3

B) 5

C) 10

D) 15

**Hint / Guided Steps:**
1. Use the first point `(0, 5)` to solve for `a`. Substitute `x = 0` and `y = 5` into the equation: `5 = a * b^0`. Recall that `b^0 = 1`. Find `a`.
2. Rewrite the equation with this value of `a`: `y = 5 * b^x`.
3. Use the second point `(1, 15)` to solve for `b`. Substitute `x = 1` and `y = 15` into the updated equation: `15 = 5 * b^1`.
4. Solve for `b` by dividing both sides by 5.

### Question 5
**Difficulty:** Medium

A system of inequalities is graphed in the xy-plane, and the solution set is represented by a shaded region. Which of the following points lies in the shaded region?
y > x - 2
y < -2x + 4

A) (3, 2)

B) (0, 0)

C) (2, -2)

D) (1, 4)

**Hint / Guided Steps:**
1. To see if a point is in the shaded region (the solution set), test the coordinates `(x, y)` of each option in both inequalities.
2. The correct point must make both inequalities true.
3. Substitute the points into:
   - `y > x - 2`
   - `y < -2x + 4`
4. Test option B (0, 0): Is `0 > 0 - 2`? And is `0 < -2(0) + 4`?
5. Repeat for other options if necessary to find the one that satisfies both.

### Question 6
**Difficulty:** Medium

The graph of y = f(x) is shown in the xy-plane. The graph of y = g(x) is defined by g(x) = f(x) + 3. Which of the following describes the relationship between the graph of g and the graph of f?

A) The graph of g is the graph of f shifted 3 units to the right.

B) The graph of g is the graph of f shifted 3 units to the left.

C) The graph of g is the graph of f shifted 3 units up.

D) The graph of g is the graph of f shifted 3 units down.

**Hint / Guided Steps:**
1. Recall the rules for vertical and horizontal transformations of graphs:
   - `f(x) + c` shifts the graph vertically up by `c` units.
   - `f(x) - c` shifts the graph vertically down by `c` units.
   - `f(x - c)` shifts the graph horizontally right by `c` units.
   - `f(x + c)` shifts the graph horizontally left by `c` units.
2. Match the expression `g(x) = f(x) + 3` to the correct transformation rule.

### Question 7
**Difficulty:** Medium

The graph of a polynomial function has x-intercepts at -2, 1, and 3. Which of the following could be the equation representing this graph?

A) y = (x - 2)(x + 1)(x + 3)

B) y = (x + 2)(x - 1)(x - 3)

C) y = (x + 2)^2 * (x - 1)(x - 3)

D) y = (x - 2)^2 * (x + 1)(x + 3)

**Hint / Guided Steps:**
1. Recall the Factor Theorem: if a graph has an x-intercept at `x = c` (which means `f(c) = 0`), then `(x - c)` is a factor of the polynomial.
2. Identify the factors corresponding to each of the given x-intercepts:
   - For intercept `-2`, the factor is `(x - (-2)) = (x + 2)`.
   - For intercept `1`, the factor is `(x - 1)`.
   - For intercept `3`, the factor is `(x - 3)`.
3. Combine these factors to write the basic form of the polynomial equation: `y = a(x + 2)(x - 1)(x - 3)`.
4. Look at the options and find the one that matches this factor structure.

### Question 8
**Difficulty:** Hard

The graph of the rational function y = (x - 2) / (x^2 - 9) is shown in the xy-plane. At which lines does the graph have vertical asymptotes?

A) x = 2 only

B) x = 3 only

C) x = 3 and x = -3

D) y = 0

**Hint / Guided Steps:**
1. Recall that a rational function has a vertical asymptote at the x-values that make the denominator equal to 0 (provided the numerator is not also 0 at those values).
2. Set the denominator equal to 0: `x^2 - 9 = 0`.
3. Solve for `x` by factoring the difference of squares: `(x - 3)(x + 3) = 0`.
4. Identify the two values of `x` where the denominator is 0.

### Question 9
**Difficulty:** Hard

In the xy-plane, a circle is tangent to the y-axis at the point (0, 4) and has its center at the point (3, 4). Which of the following is the equation of the circle?

A) (x - 3)^2 + (y - 4)^2 = 9

B) (x + 3)^2 + (y + 4)^2 = 9

C) (x - 3)^2 + (y - 4)^2 = 3

D) (x - 3)^2 + (y - 4)^2 = 16

**Hint / Guided Steps:**
1. Recall the standard equation of a circle: `(x - h)^2 + (y - k)^2 = r^2`, where `(h, k)` is the center and `r` is the radius.
2. Substitute the given center `(3, 4)` into the equation: `(x - 3)^2 + (y - 4)^2 = r^2`.
3. Determine the radius `r`. The circle is centered at `(3, 4)` and is tangent to the y-axis (the line `x = 0`) at `(0, 4)`. The distance from the center `(3, 4)` to the tangent point `(0, 4)` is the horizontal distance: `3 - 0 = 3` units. So, `r = 3`.
4. Calculate `r^2` and substitute it back into the equation.

### Question 10
**Difficulty:** Hard

The graph of the quadratic function y = ax^2 + bx + c has its vertex at (3, 2) and passes through the point (1, -6). What is the value of a?

A) -2

B) -1

C) 2

D) 4

**Hint / Guided Steps:**
1. Start by writing the quadratic equation in vertex form: `y = a(x - h)^2 + k`.
2. Substitute the vertex coordinates `(3, 2)` into the equation: `y = a(x - 3)^2 + 2`.
3. Use the given point `(1, -6)` to solve for the coefficient `a`. Substitute `x = 1` and `y = -6` into the equation: `-6 = a(1 - 3)^2 + 2`.
4. Simplify inside the parentheses: `(1 - 3) = -2`.
5. Square the result: `(-2)^2 = 4`.
6. Rewrite the equation: `-6 = 4a + 2`.
7. Solve the linear equation for `a`. Subtract 2 from both sides, then divide by 4.
