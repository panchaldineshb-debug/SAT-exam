### Question 1
**Difficulty:** Easy

What is the value of x that satisfies the equation 3^(2x - 1) = 27?

A) 1

B) 2

C) 3

D) 4

**Hint / Guided Steps:**
1. Express both sides of the equation with the same base. Note that `27` can be written as `3^3`.
2. Rewrite the equation: `3^(2x - 1) = 3^3`.
3. Since the bases are the same, equate the exponents: `2x - 1 = 3`.
4. Solve the linear equation for `x` by adding 1 to both sides and then dividing by 2.

### Question 2
**Difficulty:** Easy

In the xy-plane, the graph of y = (x - 4)^2 + 7 is a parabola. What are the coordinates of the vertex of the parabola?

A) (-4, 7)

B) (4, 7)

C) (-4, -7)

D) (4, -7)

**Hint / Guided Steps:**
1. Recall the vertex form of a quadratic equation: `y = a(x - h)^2 + k`, where `(h, k)` is the vertex of the parabola.
2. Compare the given equation `y = (x - 4)^2 + 7` with the vertex form:
   - Identify `h` from `(x - 4)^2`
   - Identify `k` from the constant term `+ 7`
3. Write down the coordinates `(h, k)`.

### Question 3
**Difficulty:** Easy

Which of the following is equivalent to the expression ((x^2 * y^3)^4) / (x * y^2)^2?

A) x^4 * y^6

B) x^6 * y^8

C) x^6 * y^10

D) x^8 * y^10

**Hint / Guided Steps:**
1. Apply the power of a power rule `(a^m)^n = a^(m*n)` to simplify the numerator and denominator:
   - Numerator: `(x^2 * y^3)^4 = x^(2*4) * y^(3*4) = x^8 * y^12`.
   - Denominator: `(x * y^2)^2 = x^2 * y^(2*2) = x^2 * y^4`.
2. Write the simplified fraction: `(x^8 * y^12) / (x^2 * y^4)`.
3. Apply the quotient rule of exponents `(a^m / a^n) = a^(m - n)` to combine the x terms and y terms:
   - For x: `x^(8 - 2)`
   - For y: `y^(12 - 4)`
4. Combine the results.

### Question 4
**Difficulty:** Medium

If x + y = 10 and xy = 21, what is the value of x^2 + y^2?

A) 58

B) 79

C) 100

D) 142

**Hint / Guided Steps:**
1. Recall the algebraic identity for the square of a binomial: `(x + y)^2 = x^2 + 2xy + y^2`.
2. Rearrange the identity to solve for `x^2 + y^2`: `x^2 + y^2 = (x + y)^2 - 2xy`.
3. Substitute the given values `x + y = 10` and `xy = 21` into the rearranged equation: `(10)^2 - 2(21)`.
4. Calculate the values: evaluate the square of 10 and multiply 2 by 21, then subtract.

### Question 5
**Difficulty:** Medium

The polynomial f(x) = x^3 - 2x^2 + kx - 6, where k is a constant, is divisible by (x - 3). What is the value of k?

A) -1

B) 1

C) 2

D) 3

**Hint / Guided Steps:**
1. Recall the Remainder Theorem: if a polynomial `f(x)` is divisible by `(x - c)`, then the remainder `f(c)` must equal 0.
2. Here, the polynomial is divisible by `(x - 3)`, so substitute `x = 3` into `f(x)` and set the expression equal to 0: `(3)^3 - 2(3)^2 + k(3) - 6 = 0`.
3. Simplify the terms: `27 - 2(9) + 3k - 6 = 0`.
4. Combine the constant terms and solve the equation for `k`.

### Question 6
**Difficulty:** Medium

Which of the following represents the solutions to the system of equations below?
y = x^2 - 4x + 3
y = 2x - 5

A) (2, -1) and (4, 3)

B) (1, -3) and (5, 5)

C) (2, -1) only

D) (4, 3) only

**Hint / Guided Steps:**
1. Since both equations are solved for `y`, set them equal to each other to solve for `x`: `x^2 - 4x + 3 = 2x - 5`.
2. Move all terms to one side to set the quadratic equation equal to 0: `x^2 - 6x + 8 = 0`.
3. Factor the quadratic equation: find two numbers that multiply to 8 and add to -6. The factors will be in the form `(x - r1)(x - r2) = 0`.
4. Solve for the two possible values of `x`.
5. Substitute each `x` value back into the linear equation `y = 2x - 5` to find the corresponding `y` values.

### Question 7
**Difficulty:** Medium

If x > 0, which of the following is equivalent to the expression \sqrt{50x^5} / \sqrt{2x^3}?

A) 5x

B) 5x^2

C) 25x

D) 25x^2

**Hint / Guided Steps:**
1. Use the quotient property of radicals: `\sqrt{a} / \sqrt{b} = \sqrt{a / b}`.
2. Rewrite the expression under a single radical sign: `\sqrt{50x^5 / 2x^3}`.
3. Simplify the fraction inside the radical:
   - Divide the coefficients: `50 / 2`.
   - Subtract the exponents of the x terms: `x^(5 - 3)`.
4. This results in: `\sqrt{25x^2}`.
5. Take the square root of the coefficient and the variable term.

### Question 8
**Difficulty:** Hard

The quadratic equation y = 2x^2 - 12x + 11 can be rewritten in vertex form as y = a(x - h)^2 + k. What is the value of h + k?

A) -4

B) -1

C) 3

D) 10

**Hint / Guided Steps:**
1. Convert the equation to vertex form by completing the square.
2. Factor the coefficient of `x^2` out of the x terms: `y = 2(x^2 - 6x) + 11`.
3. Inside the parentheses, add the value needed to make a perfect square trinomial: `(-6 / 2)^2 = 9`.
4. Since you added 9 inside parentheses that are multiplied by 2, you have added 18 to the equation. To balance this, subtract 18 outside: `y = 2(x^2 - 6x + 9) + 11 - 18`.
5. Factor the binomial inside the parentheses and combine the constants outside: `y = 2(x - 3)^2 - 7`.
6. Identify the values of `h` and `k` from this equation: `y = a(x - h)^2 + k`.
7. Add the values: `h + k`.

### Question 9
**Difficulty:** Hard

If x > 0 and x - 3\sqrt{x} - 4 = 0, what is the value of x?

A) 1

B) 4

C) 16

D) 25

**Hint / Guided Steps:**
1. This equation is quadratic in form. Use substitution to simplify it. Let a new variable `u = \sqrt{x}`. Since `u = \sqrt{x}`, it follows that `u^2 = x`.
2. Rewrite the equation in terms of `u`: `u^2 - 3u - 4 = 0`.
3. Factor the quadratic equation in terms of `u`: `(u - 4)(u + 1) = 0`.
4. Solve for `u`: `u = 4` or `u = -1`.
5. Recall that `u = \sqrt{x}`. Since the principal square root of a real number is always non-negative, discard the negative solution: `\sqrt{x} = 4`.
6. Solve for `x` by squaring both sides of the equation.

### Question 10
**Difficulty:** Hard

If x^2 - 4x + 1 = 0, what is the value of x^2 + 1/x^2?

A) 14

B) 16

C) 18

D) 20

**Hint / Guided Steps:**
1. Do not try to solve for `x` directly. Instead, manipulate the given equation.
2. Divide every term of the given equation `x^2 - 4x + 1 = 0` by `x`: `(x^2 / x) - (4x / x) + (1 / x) = 0`.
3. Simplify this to: `x - 4 + 1/x = 0`, which means `x + 1/x = 4`.
4. Square both sides of the equation `x + 1/x = 4`: `(x + 1/x)^2 = 4^2`.
5. Expand the left side: `x^2 + 2 * x * (1/x) + 1/x^2 = 16`, which simplifies to `x^2 + 2 + 1/x^2 = 16`.
6. Subtract 2 from both sides to find the value of `x^2 + 1/x^2`.
