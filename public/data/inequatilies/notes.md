        * y >= 2x + 1 -> 3 >= 2(0) + 1 -> 3 >= 1 (True).
        * y < -x + 4 -> 3 < -0 + 4 -> 3 < 4 (True).
        * Since (0, 3) satisfies both inequalities, Option B is the solution.
