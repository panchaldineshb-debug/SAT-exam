# SAT Prep: Inequalities - Practice Questions (Q.md)

This file contains 10 practice questions on Inequalities for the SAT. Each question includes a multiple-choice layout followed by hints and guided steps — **no answers are given**. Work through the hints to find the solution yourself, Student!

---

### Question 1
**Difficulty:** Easy

If `3x - 5 > 13`, which of the following is a possible value of `x`?

A) 4

B) 5

C) 6

D) 7

**Hint / Guided Steps:**
1. Start by isolating `x` in the inequality `3x - 5 > 13` by adding 5 to both sides.
2. Divide both sides by 3 to find the inequality for `x`.
3. Check the given choices to find which number is strictly greater than the value you found.

### Question 2
**Difficulty:** Easy

A delivery service charges a flat fee of $10 plus $2 for each pound a package weighs. If a customer wants the total charge to be at most $30, which inequality represents the possible weights, `w`, in pounds, of the package?

A) 2w + 10 <= 30

B) 2w + 10 >= 30

C) 10w + 2 <= 30

D) 10w + 2 >= 30

**Hint / Guided Steps:**
1. Identify the constant cost (flat fee) and the variable cost (cost per pound, `w`).
2. Express the total cost as the sum of the flat fee and the variable cost.
3. Understand the phrase "at most $30" — does this mean the total cost should be less than or equal to 30, or greater than or equal to 30?
4. Choose the inequality that correctly matches this relationship.

### Question 3
**Difficulty:** Easy

Which of the following numbers is a solution to the inequality `5 - 2x >= 11`?

A) -4

B) -2

C) 0

D) 2

**Hint / Guided Steps:**
1. Solve the inequality `5 - 2x >= 11` step by step. First, subtract 5 from both sides.
2. Now, you need to divide both sides of the inequality by -2 to isolate `x`.
3. Remember the golden rule of inequalities: what happens to the direction of the inequality sign when you multiply or divide both sides by a negative number?
4. Once you have the final inequality for `x`, look at the answer choices to see which number satisfies it.

### Question 4
**Difficulty:** Medium

A movie theater sells student tickets for $8 each and adult tickets for $12 each. The theater needs to make at least $240 from ticket sales for a specific show and can seat at most 25 people. If `s` represents the number of student tickets sold and `a` represents the number of adult tickets sold, which system of inequalities represents this situation?

A) s + a <= 25 and 8s + 12a >= 240

B) s + a >= 25 and 8s + 12a <= 240

C) s + a <= 25 and 8s + 12a <= 240

D) s + a >= 25 and 8s + 12a >= 240

**Hint / Guided Steps:**
1. Look at the constraint on the total number of people: the theater can seat "at most 25 people". Does this mean `s + a` is less than or equal to 25, or greater than or equal to 25?
2. Look at the revenue constraint: the theater needs to make "at least $240". Does this mean the total revenue from student tickets (`8s`) and adult tickets (`12a`) is less than or equal to 240, or greater than or equal to 240?
3. Combine these two inequalities to find the correct system from the choices.

### Question 5
**Difficulty:** Medium

A system of inequalities is given below:
`y >= 2x + 1`
`y < -x + 4`

Which of the following points `(x, y)` is a solution to the system?

A) (1, 1)

B) (0, 3)

C) (2, 5)

D) (3, 0)

**Hint / Guided Steps:**
1. For a point to be a solution to the system, it must satisfy both inequalities.
2. Test each option by plugging the first coordinate as `x` and the second coordinate as `y` into the first inequality, `y >= 2x + 1`. Eliminate any choices that make this statement false.
3. For the remaining choices, plug the coordinates into the second inequality, `y < -x + 4`. Find the one that makes this statement true.

### Question 6
**Difficulty:** Medium

If `|2x - 3| <= 7`, what is the maximum possible value of `x`?

A) -2

B) 2

C) 5

D) 10

**Hint / Guided Steps:**
1. Recall how to rewrite an absolute value inequality of the form `|expression| <= value`. It can be expressed as a compound inequality: `-value <= expression <= value`.
2. Rewrite `|2x - 3| <= 7` as `-7 <= 2x - 3 <= 7`.
3. Solve for `x` by adding 3 to all three parts of the inequality, and then dividing all parts by 2.
4. Identify the range of possible values for `x`. What is the largest (maximum) number in this range?

### Question 7
**Difficulty:** Medium-Hard

In the xy-plane, if a point `(a, b)` lies in the solution set of the system of inequalities below, what is the minimum possible value of `b`?
`y >= -3x + 6`
`y >= 2x - 4`

A) -4

B) -2

C) 0

D) 2

**Hint / Guided Steps:**
1. Visualize the boundary lines: `y = -3x + 6` (a line sloping downwards) and `y = 2x - 4` (a line sloping upwards). The solution set contains the region above (or on) both lines.
2. The minimum value of `y` (which is `b` for any point `(a, b)` in the solution set) occurs at the intersection of the two boundary lines where the boundary lines meet.
3. Set the equations of the boundary lines equal to each other to find the `x`-coordinate of the intersection point: `-3x + 6 = 2x - 4`.
4. Solve for `x`, then substitute that value back into either line equation to find the corresponding `y`-coordinate. This will be the minimum possible value of `b`.

### Question 8
**Difficulty:** Medium-Hard

If `a < b` and `c < 0`, which of the following statements must be true?
I. `ac < bc`
II. `a + c < b + c`
III. `a - c < b - c`

A) II only

B) I and II only

C) II and III only

D) I, II, and III

**Hint / Guided Steps:**
1. Analyze statement I: `ac < bc`. Since `c < 0`, `c` is a negative number. Remember that multiplying both sides of an inequality by a negative number reverses the inequality sign.
2. Analyze statement II: `a + c < b + c`. Adding any number (positive or negative) to both sides of an inequality does not affect the direction of the sign.
3. Analyze statement III: `a - c < b - c`. Subtracting any number from both sides of an inequality does not affect the direction of the sign.
4. Combine your conclusions to select the correct option.

### Question 9
**Difficulty:** Hard

A system of inequalities consists of `y > x + 2` and `y < -2x + 8`. If `(x, y)` is a solution to the system and both `x` and `y` are integers, what is the value of `y`?

A) 3

B) 4

C) 5

D) 6

**Hint / Guided Steps:**
1. Combine the two inequalities to bound `y` between expressions of `x`: `x + 2 < y < -2x + 8`.
2. For a solution `y` to exist, the lower bound of `y` must be strictly less than the upper bound: `x + 2 < -2x + 8`.
3. Solve this inequality for `x`.
4. Since `x` must be an integer, find the integer value(s) of `x` that satisfy your inequality.
5. Plug that integer value of `x` back into the range `x + 2 < y < -2x + 8` and identify the integer value of `y` that fits in this range.

### Question 10
**Difficulty:** Hard

A farmer wants to plant at least 10 acres of corn and wheat. Corn costs $50 per acre to plant, and wheat costs $30 per acre to plant. The farmer has a budget of at most $420 for planting. If the farmer wants to maximize the number of acres of corn planted, what is the maximum number of acres of corn they can plant?

A) 4

B) 5

C) 6

D) 8

**Hint / Guided Steps:**
1. Let `c` be the number of acres of corn and `w` be the number of acres of wheat.
2. Write the system of inequalities representing the constraints:
   - Total acreage: `c + w >= 10`
   - Total cost: `50c + 30w <= 420`
3. We want to maximize `c`. To leave as much money as possible for corn, we should minimize the acreage of wheat. From the acreage constraint, the minimum wheat we can plant for a given `c` is `w = 10 - c`.
4. Substitute `w = 10 - c` into the cost inequality: `50c + 30(10 - c) <= 420`.
5. Solve this inequality for `c` to find the upper bound on corn acreage.
