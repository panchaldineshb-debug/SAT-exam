### Question 1
**Difficulty:** Easy

Which of the following is equivalent to the expression sin(\pi/6)?

A) cos(\pi/6)

B) cos(\pi/3)

C) sin(\pi/3)

D) cos(2\pi/3)

**Hint / Guided Steps:**
1. Recall the complementary angle identity in radians: `sin(\theta) = cos(\pi/2 - \theta)`.
2. Substitute the given angle `\theta = \pi/6` into the identity: `cos(\pi/2 - \pi/6)`.
3. Find a common denominator to subtract the fractions: `\pi/2 = 3\pi/6`.
4. Perform the subtraction: `3\pi/6 - \pi/6 = 2\pi/6`.
5. Simplify the fraction.

### Question 2
**Difficulty:** Easy

An angle \theta has a measure of 5\pi/4 radians. In which quadrant of the coordinate plane does the terminal side of the angle lie?

A) Quadrant I

B) Quadrant II

C) Quadrant III

D) Quadrant IV

**Hint / Guided Steps:**
1. Recall the radian measures at the boundaries of the quadrants in standard position:
   - Positive x-axis: `0` (or `2\pi`)
   - Positive y-axis: `\pi/2` (or `0.5\pi`)
   - Negative x-axis: `\pi` (or `1.0\pi`)
   - Negative y-axis: `3\pi/2` (or `1.5\pi`)
2. Convert `5\pi/4` to a decimal coefficient: `5 / 4 = 1.25\pi`.
3. Compare `1.25\pi` to the boundary values: notice that `1.25\pi` is between `\pi` (`1.0\pi`) and `3\pi/2` (`1.5\pi`).
4. Identify which quadrant corresponds to the region between the negative x-axis and negative y-axis.

### Question 3
**Difficulty:** Easy

What is the period of the trigonometric function f(x) = 3 * sin(2x)?

A) \pi/2

B) \pi

C) 2\pi

D) 3\pi

**Hint / Guided Steps:**
1. Recall that the standard sine function `y = a * sin(bx)` has a period given by the formula: `Period = 2\pi / b`.
2. Identify the coefficient `b` from the given function `f(x) = 3 * sin(2x)` (which is 2).
3. Substitute `b = 2` into the period formula: `2\pi / 2`.
4. Simplify the expression.

### Question 4
**Difficulty:** Medium

If cos(\theta) = -4/5 and the terminal side of the angle lies in Quadrant II, what is the value of sin(\theta)?

A) -3/5

B) -3/4

C) 3/5

D) 4/5

**Hint / Guided Steps:**
1. Recall the fundamental Pythagorean trigonometric identity: `sin^2(\theta) + cos^2(\theta) = 1`.
2. Substitute the given value of `cos(\theta) = -4/5` into the identity: `sin^2(\theta) + (-4/5)^2 = 1`.
3. Square the fraction: `(-4/5)^2 = 16/25`.
4. Solve for `sin^2(\theta)`: `sin^2(\theta) = 1 - 16/25 = 9/25`.
5. Take the square root: `sin(\theta) = \sqrt{9/25} = 3/5` or `-3/5`.
6. Determine the sign of the sine function in Quadrant II. Recall that in Quadrant II, sine is positive.

### Question 5
**Difficulty:** Medium

If sin(x) = cos(2x - 15), where x and 2x - 15 are the measures of acute angles in degrees, what is the value of x?

A) 25

B) 35

C) 45

D) 55

**Hint / Guided Steps:**
1. Recall the cofunction identity in degrees: `sin(A) = cos(B)` when the angles A and B are complementary (they add up to 90 degrees).
2. Set up the equation: `x + (2x - 15) = 90`.
3. Combine like terms: `3x - 15 = 90`.
4. Solve the linear equation for `x`. Add 15 to both sides, then divide by 3.

### Question 6
**Difficulty:** Medium

The graph of the function y = a * cos(bx) in the xy-plane has an amplitude of 4 and a period of \pi/3. If a > 0 and b > 0, what are the values of a and b?

A) a = 4, b = 3

B) a = 4, b = 6

C) a = 2, b = 3

D) a = 2, b = 6

**Hint / Guided Steps:**
1. Recall that the amplitude of the function `y = a * cos(bx)` is given by `|a|`. Since `a > 0`, the amplitude is `a`. Therefore, `a = 4`.
2. Recall that the period of the function is given by the formula: `Period = 2\pi / b`.
3. Set the given period equal to the formula: `\pi/3 = 2\pi / b`.
4. Solve this equation for `b`. Cross-multiply: `\pi * b = 6\pi`. Divide both sides by `\pi`.

### Question 7
**Difficulty:** Medium

An angle \theta is in standard position. If sin(\theta) < 0 and cos(\theta) > 0, in which quadrant does the terminal side of the angle lie?

A) Quadrant I

B) Quadrant II

C) Quadrant III

D) Quadrant IV

**Hint / Guided Steps:**
1. Recall the signs of the trigonometric functions in each quadrant, which depend on the signs of x and y coordinates (`cos` relates to x, `sin` relates to y):
   - Quadrant I: x > 0, y > 0 (both cos and sin are positive)
   - Quadrant II: x < 0, y > 0 (cos is negative, sin is positive)
   - Quadrant III: x < 0, y < 0 (both cos and sin are negative)
   - Quadrant IV: x > 0, y < 0 (cos is positive, sin is negative)
2. Match the given conditions `cos(\theta) > 0` (positive) and `sin(\theta) < 0` (negative) to the correct quadrant.

### Question 8
**Difficulty:** Hard

Which of the following is the value of the expression sin^2(\pi/8) + sin^2(3\pi/8)?

A) 1/2

B) 1

C) \sqrt{2}/2

D) 2

**Hint / Guided Steps:**
1. Observe the two angles in the expression: `\pi/8` and `3\pi/8`.
2. Check if their sum equals a key angle: `\pi/8 + 3\pi/8 = 4\pi/8 = \pi/2` (90 degrees). Since they add up to `\pi/2`, they are complementary angles.
3. Express one angle in terms of the other: `3\pi/8 = \pi/2 - \pi/8`.
4. Apply the complementary angle identity: `sin(3\pi/8) = sin(\pi/2 - \pi/8) = cos(\pi/8)`.
5. Substitute this back into the original expression: `sin^2(\pi/8) + cos^2(\pi/8)`.
6. Use the fundamental Pythagorean identity: `sin^2(\theta) + cos^2(\theta) = 1`.

### Question 9
**Difficulty:** Hard

If \tan(x) = k, where x is an acute angle and k is a positive constant, which of the following represents cos(x) in terms of k?

A) k / \sqrt{k^2 + 1}

B) 1 / \sqrt{k^2 + 1}

C) \sqrt{k^2 + 1}

D) k^2 + 1

**Hint / Guided Steps:**
1. Visualize the tangent relationship on a right triangle: `tan(x) = Opposite / Adjacent = k / 1`. Let the opposite side be `k` and the adjacent side be `1`.
2. Find the hypotenuse `H` using the Pythagorean theorem: `H^2 = k^2 + 1^2 = k^2 + 1`. Take the square root to find `H = \sqrt{k^2 + 1}`.
3. Recall the cosine definition: `cos(x) = Adjacent / Hypotenuse`.
4. Substitute the adjacent side (1) and the hypotenuse you calculated into the fraction.

### Question 10
**Difficulty:** Hard

The height, h, in feet, of the water in a tidal bay t hours after midnight is modeled by the function h(t) = 6 * sin(\pi * t / 6) + 10. What is the maximum height, in feet, of the water in the bay?

A) 6

B) 10

C) 16

D) 22

**Hint / Guided Steps:**
1. Analyze the components of the trigonometric function: `h(t) = 6 * sin(\pi * t / 6) + 10`.
2. Recall that the standard sine function `sin(\theta)` has a maximum value of 1.
3. To find the maximum height, replace the entire sine term `sin(\pi * t / 6)` with its maximum value of 1.
4. Set up the equation: `Maximum height = 6 * (1) + 10`.
5. Calculate the result.
