### Question 1
**Difficulty:** Easy

If f(x) = 3x^2 - 5x + 2, what is the value of f(-2)?

A) 4

B) 12

C) 20

D) 24

**Hint / Guided Steps:**
1. Remember that f(-2) means evaluating the function f(x) by replacing every instance of x with -2.
2. Substitute -2 into the function expression: `3 * (-2)^2 - 5 * (-2) + 2`.
3. Simplify the exponent first: `(-2)^2 = 4`.
4. Perform the multiplications: `3 * 4` and `-5 * (-2)`. Remember that a negative number times a negative number is positive.
5. Add the resulting values together: `12 + 10 + 2`.

### Question 2
**Difficulty:** Easy

The table below shows some values of the functions f and g.

| x | f(x) | g(x) |
|---|------|------|
| 1 |  3   |  2   |
| 2 |  5   |  1   |
| 3 |  2   |  3   |

What is the value of f(g(1))?

A) 2

B) 3

C) 5

D) 6

**Hint / Guided Steps:**
1. This is a composite function problem. Evaluate the inner function first: `g(1)`.
2. Look at the table. Find `x = 1` in the first column, and look at the corresponding value in the `g(x)` column to find `g(1)`.
3. Take this output value and substitute it as the input for the outer function `f`. So, you will evaluate `f(output)`.
4. Look at the table again. Find the row where `x` equals that output value, and look at the corresponding value in the `f(x)` column to find the final answer.

### Question 3
**Difficulty:** Easy

A plumber charges a total fee, C(h), in dollars, for a service call that lasts h hours. The fee is modeled by the function C(h) = 45h + 75. What does the number 75 represent in this context?

A) The hourly rate of the plumber, in dollars per hour.

B) The flat fee charged by the plumber for the service call, in dollars.

C) The total cost for 45 hours of work, in dollars.

D) The number of hours the plumber worked.

**Hint / Guided Steps:**
1. Identify the form of the function: `C(h) = 45h + 75` is a linear function in slope-intercept form (`y = mx + b`).
2. Recognize the meaning of each term in a real-world context:
   - The term with the variable `h` (which is `45h`) represents the variable cost that changes depending on the number of hours worked. Therefore, `45` represents the rate per hour.
   - The constant term `75` (the y-intercept) represents the starting cost when `h = 0` (before any hours of work are done).
3. Match this starting cost description to one of the multiple-choice options.

### Question 4
**Difficulty:** Medium

What is the domain of the function f(x) = \sqrt{2x - 8}?

A) All real numbers

B) x >= 0

C) x >= 4

D) x >= 8

**Hint / Guided Steps:**
1. Recall that the domain of a function is the set of all possible input values (x-values) for which the function is defined.
2. For a square root function to be defined with real numbers, the expression under the radical (the radicand) must be greater than or equal to 0. You cannot take the square root of a negative number in real-number functions.
3. Set up an inequality: `2x - 8 >= 0`.
4. Solve the inequality for `x`. Add 8 to both sides, then divide by 2.
5. The solution inequality represents the domain of the function.

### Question 5
**Difficulty:** Medium

If f(x) = 2x + 3 and g(x) = x^2 - 1, which of the following is the expression for g(f(x))?

A) 2x^2 + 1

B) 2x^2 + 5

C) 4x^2 + 12x + 8

D) 4x^2 + 12x + 9

**Hint / Guided Steps:**
1. To find the composite expression `g(f(x))`, you substitute the entire expression of the function `f(x)` into the function `g(x)` wherever there is an `x`.
2. Write the structure of `g(x)` with parentheses in place of x: `g(f(x)) = (f(x))^2 - 1`.
3. Substitute the expression `2x + 3` into the parentheses: `(2x + 3)^2 - 1`.
4. Expand the squared binomial: `(2x + 3)^2 = (2x + 3)(2x + 3) = 4x^2 + 12x + 9`.
5. Subtract 1 from the expanded expression: `4x^2 + 12x + 9 - 1` and combine the constants.

### Question 6
**Difficulty:** Medium

The graph of y = f(x) is shown in the xy-plane. The graph of y = g(x) is obtained by translating the graph of y = f(x) by 3 units to the right and 2 units up. Which of the following equations represents g(x)?

A) g(x) = f(x + 3) + 2

B) g(x) = f(x - 3) + 2

C) g(x) = f(x + 3) - 2

D) g(x) = f(x - 3) - 2

**Hint / Guided Steps:**
1. Recall the rules for function transformations (translations):
   - Translating a graph horizontally: `f(x - c)` shifts the graph `c` units to the right, and `f(x + c)` shifts the graph `c` units to the left.
   - Translating a graph vertically: `f(x) + d` shifts the graph `d` units up, and `f(x) - d` shifts the graph `d` units down.
2. Apply the horizontal translation of 3 units to the right to the input of `f(x)`. How does the argument of the function change?
3. Apply the vertical translation of 2 units up to the function expression. How does the term added to the function change?
4. Combine these two transformations to write the expression for `g(x)`.

### Question 7
**Difficulty:** Medium

If the function f(x) = x^2 + kx + 12, where k is a constant, has a zero at x = 3, what is another zero of the function f?

A) -4

B) -3

C) 4

D) 7

**Hint / Guided Steps:**
1. Recall that a "zero" of a function is a value of `x` for which the function outputs 0, meaning `f(3) = 0`.
2. Substitute `x = 3` into the equation and set it equal to 0: `3^2 + k(3) + 12 = 0`.
3. Simplify the equation to solve for the constant `k`: `9 + 3k + 12 = 0` -> `21 + 3k = 0`. Find `k`.
4. Substitute the value of `k` back into the original function: `f(x) = x^2 + kx + 12`.
5. To find the other zero, set this quadratic function equal to 0 and factor it: `x^2 + kx + 12 = 0`.
6. Factor the quadratic equation into the form `(x - 3)(x - r) = 0`, where `r` is the other zero. Solve for `r`.

### Question 8
**Difficulty:** Medium

In the xy-plane, the graphs of the functions f(x) = 2^x and g(x) = 8 intersect at the point (a, b). What is the value of a?

A) 2

B) 3

C) 4

D) 8

**Hint / Guided Steps:**
1. The intersection point of the graphs is where the function values are equal: `f(x) = g(x)`.
2. Set up the equation: `2^x = 8`.
3. Rewrite the number 8 as a power of 2: `8 = 2^3`.
4. Substitute this back into the equation: `2^x = 2^3`.
5. Since the bases are equal, the exponents must be equal. Solve for `x` (this value is `a`).

### Question 9
**Difficulty:** Hard

A population of bacteria in a petri dish doubles every 3 hours. If the initial population is 100 bacteria, which of the following functions models the population, P(t), after t hours?

A) P(t) = 100 + 2^(t/3)

B) P(t) = 100 * 2^(3t)

C) P(t) = 100 * 2^(t/3)

D) P(t) = 100 * (1/2)^(t/3)

**Hint / Guided Steps:**
1. Identify the type of function needed: since the population is doubling, this represents exponential growth. The general form is `P(t) = P0 * (growth factor)^exponent`, where `P0` is the initial population.
2. Identify the growth factor: since the population doubles, the base growth factor is `2`.
3. Identify the initial population `P0`: the prompt states there are `100` bacteria initially.
4. Determine the exponent: the population doubles *every 3 hours*. This means the number of doubling periods is `t / 3` (where `t` is the number of hours). For example, at `t = 3` hours, it should have doubled once (`3/3 = 1` doubling period); at `t = 6` hours, it should have doubled twice (`6/3 = 2` doubling periods).
5. Assemble the function with `P0 = 100`, base = `2`, and exponent = `t / 3`.

### Question 10
**Difficulty:** Hard

For the function f(x) = ax^2 + b, where a and b are constants, the table of values shows that f(1) = 5 and f(2) = 17. What is the value of f(3)?

A) 29

B) 33

C) 37

D) 41

**Hint / Guided Steps:**
1. Use the given values to set up a system of linear equations to solve for the constants `a` and `b`.
2. Set up the first equation using `f(1) = 5`: substitute `x = 1` into the function: `a(1)^2 + b = 5` -> `a + b = 5`.
3. Set up the second equation using `f(2) = 17`: substitute `x = 2` into the function: `a(2)^2 + b = 17` -> `4a + b = 17`.
4. Solve the system of equations. Subtract the first equation from the second equation to eliminate `b`: `(4a + b) - (a + b) = 17 - 5` -> `3a = 12`. Solve for `a`.
5. Substitute the value of `a` back into `a + b = 5` to find the value of `b`.
6. Rewrite the complete function `f(x)` using the values you found for `a` and `b`.
7. Evaluate `f(3)` by substituting `x = 3` into your completed function and calculating the result.
