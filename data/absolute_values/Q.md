# SAT Prep: Advanced Absolute Values - Practice Questions (Q.md)

This file contains 15 advanced absolute value practice questions designed for the SAT. Under each question, you will find hints and guided steps to help you arrive at the solution on your own. No final answers are provided in this file.

---

### Question 1
**Difficulty:** Medium-Hard

If |x - a| = 4 and |y - a| = 10, where a is a constant, what is the minimum possible value of the distance between x and y on the number line?

A) 4

B) 6

C) 10

D) 14

**Hints & Guided Steps:**
1. Remember that the absolute value expression |p - q| represents the distance between p and q on the number line.
2. The equation |x - a| = 4 means x is exactly 4 units away from a. Therefore, x can be either a + 4 or a - 4.
3. Similarly, interpret the equation |y - a| = 10 to find the two possible positions of y relative to a.
4. Draw these points on a number line centered at a and examine the distances between all possible pairs of x and y. Find the smallest of these distances.

### Question 2
**Difficulty:** Hard

In the inequality |3x + 12| - k <= -5, where k is a constant, for which of the following values of k does the inequality have no real solutions?

A) 4

B) 5

C) 6

D) 8

**Hints & Guided Steps:**
1. Start by isolating the absolute value expression. Add k to both sides of the inequality to get |3x + 12| <= k - 5.
2. Recall that the absolute value of any real expression is always greater than or equal to 0 (non-negative).
3. For an inequality of the form |expression| <= value to have no real solutions, the value on the right-hand side must be negative.
4. Set up an inequality for k - 5 based on this condition and solve for k. Compare your result with the given choices.

### Question 3
**Difficulty:** Hard

The function f is defined by f(x) = -2|x - h| + k, where h and k are constants. If the graph of y = f(x) in the xy-plane has its vertex at (5, 8), what is the distance between the two x-intercepts of the graph?

A) 4

B) 8

C) 10

D) 16

**Hints & Guided Steps:**
1. The standard vertex form of an absolute value function is f(x) = a|x - h| + k, where (h, k) is the vertex. Since the vertex is given as (5, 8), identify the values of h and k.
2. Write down the complete equation for f(x) using these values.
3. To find the x-intercepts, set f(x) = 0 and solve the equation for x.
4. Once you have found the two values of x, calculate the distance between them by taking the positive difference between the two solutions.

### Question 4
**Difficulty:** Medium-Hard

A manufacturer produces steel rods that must have a target length of 24.50 centimeters. A rod is considered acceptable if its length differs from the target length by at most 0.08 centimeters. If L represents the length of an acceptable steel rod, which of the following inequalities represents all possible values of L?

A) |L - 0.08| <= 24.50

B) |L - 24.50| <= 0.08

C) |L + 24.50| <= 0.08

D) |L - 24.50| >= 0.08

**Hints & Guided Steps:**
1. Translate the statement "differs from the target length of 24.50 by at most 0.08" into mathematical terms.
2. The distance between the actual length L and the target length 24.50 on the number line can be written using absolute value as |L - 24.50|.
3. The phrase "at most 0.08" means this distance must be less than or equal to 0.08.
4. Combine these two concepts to select the correct inequality.

### Question 5
**Difficulty:** Hard

How many distinct real solutions are there to the equation x^2 - 7|x| + 12 = 0?

A) One

B) Two

C) Three

D) Four

**Hints & Guided Steps:**
1. Use the algebraic identity that x^2 is equivalent to |x|^2 for all real numbers x.
2. Rewrite the given equation as |x|^2 - 7|x| + 12 = 0.
3. Let a temporary variable u = |x|. Substitute u into the equation to obtain a standard quadratic equation: u^2 - 7u + 12 = 0.
4. Factor the quadratic equation to find the possible values for u.
5. Replace u back with |x| (so |x| = first solution, and |x| = second solution). Remember that for any positive constant c, the equation |x| = c yields two real solutions (x = c and x = -c). Determine how many valid solutions exist in total.

### Question 6
**Difficulty:** Hard (Grid-In)

In the xy-plane, a region is bounded by the inequalities y >= |x - 3| and y <= 5. What is the area of this region?

**Hints & Guided Steps:**
1. Start by graphing the boundaries of the region: the V-shaped graph y = |x - 3| and the horizontal line y = 5.
2. The vertex of the V-shaped graph is at (3, 0).
3. The region of interest lies above the V-shape (y >= |x - 3|) and below the line y = 5 (y <= 5), which forms a triangle.
4. Find the points where the line y = 5 intersects the boundary lines of the absolute value graph (where |x - 3| = 5).
5. Use the formula for the area of a triangle: Area = 0.5 * base * height. The base is the distance between the two intersection points on the line y = 5, and the height is the vertical distance from the vertex (3, 0) up to the line y = 5.

### Question 7
**Difficulty:** Hard

What is the sum of all real solutions to the equation |2x - 6| = x + 3?

A) 1

B) 8

C) 9

D) 10

**Hints & Guided Steps:**
1. Split the absolute value equation |A| = B into two separate algebraic cases:
   - Case 1: 2x - 6 = x + 3
   - Case 2: 2x - 6 = -(x + 3)
2. Solve Case 1 to find a candidate solution for x.
3. Solve Case 2 to find another candidate solution for x.
4. **Crucial Check:** Because the right side of the original equation contains a variable expression (x + 3), you must plug both candidate solutions back into the original equation |2x - 6| = x + 3 to verify if either solution is extraneous.
5. Add together only the valid solutions to find the final sum.

### Question 8
**Difficulty:** Medium-Hard

The temperature of a scientific oven must be kept between 145 degrees Celsius and 165 degrees Celsius, inclusive. If T represents the temperature of the oven in degrees Celsius, which of the following inequalities represents the acceptable temperature range?

A) |T - 155| <= 10

B) |T - 155| <= 20

C) |T - 10| <= 155

D) |T - 160| <= 5

**Hints & Guided Steps:**
1. Any range of values A <= T <= B can be represented in absolute value form as |T - midpoint| <= radius.
2. Find the midpoint of the range by calculating the average of the two endpoints: (145 + 165) / 2.
3. Find the radius of the range (the distance from the midpoint to either endpoint) by calculating: maximum value - midpoint.
4. Substitute your midpoint and radius into the general form |T - midpoint| <= radius.

### Question 9
**Difficulty:** Hard

If |2x - a| = 8, where a is a constant, and the two solutions for x are p and q such that p - q = 8, what is the value of a?

A) 8

B) 16

C) There is not enough information.

D) The value of a can be any real number.

**Hints & Guided Steps:**
1. Write down the two cases for the equation |2x - a| = 8:
   - Case 1: 2x - a = 8
   - Case 2: 2x - a = -8
2. Solve each case for x to express the two solutions, p and q, in terms of the constant a. Let p be the larger solution and q be the smaller solution.
3. You should get: p = (a + 8) / 2 and q = (a - 8) / 2.
4. Calculate the difference p - q using these expressions.
5. Notice what happens to the variable a in the subtraction. What does this tell you about the relationship between the distance between the solutions and the value of a?

### Question 10
**Difficulty:** Hard

For all x < 2, which of the following is equivalent to the expression |x - 2| + |3 - x|?

A) 1

B) 5

C) 5 - 2x

D) 2x - 5

**Hints & Guided Steps:**
1. Recall the definition of absolute value: |u| = u if u is positive or zero, and |u| = -u if u is negative.
2. Determine the sign of each term inside the absolute value brackets when x is strictly less than 2:
   - For x < 2, is the expression (x - 2) positive or negative? Since it is negative, remove the absolute value bars and multiply the expression by -1: -(x - 2).
   - For x < 2, is the expression (3 - x) positive or negative? Since it is positive, remove the absolute value bars without changing any signs: (3 - x).
3. Write the simplified sum by adding the two modified expressions together: -(x - 2) + (3 - x).
4. Expand and combine like terms to find the equivalent expression.

### Question 11
**Difficulty:** Medium-Hard

How many integer values of x satisfy the inequality |2x - 5| < 9?

A) 7

B) 8

C) 9

D) 10

**Hints & Guided Steps:**
1. Express the absolute value inequality |2x - 5| < 9 as a compound inequality: -9 < 2x - 5 < 9.
2. Solve for x by first adding 5 to all three parts of the inequality.
3. Divide all three parts by 2 to isolate x, giving you a range of the form: lower_bound < x < upper_bound.
4. List all the integers (integers are whole numbers, both positive, negative, and zero) that lie strictly between your lower and upper bounds, and count how many there are.

### Question 12
**Difficulty:** Hard

The graphs of the functions f(x) = |x - 4| + 3 and g(x) = -|x - 4| + k intersect at exactly two points in the xy-plane. Which of the following describes all possible values of the constant k?

A) k > 3

B) k < 3

C) k > 6

D) k = 3

**Hints & Guided Steps:**
1. Visualize the graphs of f(x) and g(x).
2. f(x) = |x - 4| + 3 is a V-shaped graph that opens upwards. Its vertex is located at (4, 3).
3. g(x) = -|x - 4| + k is a V-shaped graph that opens downwards. Its vertex is located at (4, k).
4. Since both vertices have the same x-coordinate (x = 4), they lie directly above or below each other on the same vertical line.
5. For a V-shape opening upwards (vertex at y = 3) and a V-shape opening downwards (vertex at y = k) to intersect at exactly two points, where must the vertex of the downward-opening graph be relative to the vertex of the upward-opening graph?
6. Translate this geometric relationship into an inequality for k.

### Question 13
**Difficulty:** Hard

The equation |3x - 4| = 2x - 1 has how many distinct real solutions?

A) Zero

B) One

C) Two

D) Infinitely many

**Hints & Guided Steps:**
1. Solve the absolute value equation by separating it into two cases:
   - Case 1: 3x - 4 = 2x - 1
   - Case 2: 3x - 4 = -(2x - 1)
2. Solve each case to find potential solutions for x.
3. Test each potential solution by substituting it back into the original equation |3x - 4| = 2x - 1.
4. Note that because the left side is an absolute value (which must be non-negative), the right side expression 2x - 1 must also evaluate to a non-negative number for the solution to be valid. Check if both solutions satisfy this condition.

### Question 14
**Difficulty:** Hard (Grid-In)

If |x - 2| <= 4 and |y + 3| <= 5, what is the maximum possible value of the expression |x - y|?

**Hints & Guided Steps:**
1. Solve the inequality |x - 2| <= 4 to find the range of possible values for x. Write this as: minimum_x <= x <= maximum_x.
2. Solve the inequality |y + 3| <= 5 to find the range of possible values for y. Write this as: minimum_y <= y <= maximum_y.
3. The expression |x - y| represents the distance between x and y on the number line.
4. To make this distance as large as possible, you need to find the pair of points (one from the x-interval and one from the y-interval) that are furthest apart.
5. Calculate the distance between maximum_x and minimum_y, and the distance between minimum_x and maximum_y. Choose the maximum of these distances.

### Question 15
**Difficulty:** Hard

What is the minimum value of the function f(x) = |x - 1| + |x - 5| + |x - 10| for all real numbers x?

A) 4

B) 9

C) 10

D) 14

**Hints & Guided Steps:**
1. Geometrically, f(x) represents the sum of the distances from a point x to the points 1, 5, and 10 on the number line.
2. Consider how the function behaves in different intervals on the number line (e.g., when x is less than 1, between 1 and 5, between 5 and 10, or greater than 10).
3. Calculate the value of the function at each of the critical boundary points: f(1), f(5), and f(10).
4. Recall a general mathematical principle: for any odd number of points on a number line, the sum of the absolute distances to those points is minimized when x is equal to the median value of the points.
5. Identify the median of the set {1, 5, 10} and evaluate the function f(x) at that value.
