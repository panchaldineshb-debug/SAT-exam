### Question 1
**Difficulty:** Easy

If f(x) = x^2 - 3x and g(x) = 2x + 1, what is the value of f(g(2))?

A) 5

B) 10

C) 15

D) 25

**Hint / Guided Steps:**
1. This is a composite function problem. Evaluate the inner function first: `g(2)`.
2. Substitute 2 into the equation for `g(x)`: `g(2) = 2(2) + 1`. Calculate the value.
3. Take this output value and substitute it as the input `x` in the outer function `f(x)`.
4. Evaluate `f(output)`: square the value and subtract 3 times the value.

### Question 2
**Difficulty:** Easy

If the graph of y = f(x) is shifted 4 units down in the xy-plane, which of the following equations represents the new graph?

A) y = f(x - 4)

B) y = f(x + 4)

C) y = f(x) - 4

D) y = f(x) + 4

**Hint / Guided Steps:**
1. Recall the rules for function transformations:
   - Shifting a graph horizontally: `f(x - c)` shifts the graph right, and `f(x + c)` shifts the graph left.
   - Shifting a graph vertically: `f(x) + d` shifts the graph up, and `f(x) - d` shifts the graph down.
2. Identify which rule corresponds to a vertical translation of 4 units downward.

### Question 3
**Difficulty:** Easy

What is the y-intercept of the graph of f(x) = 3 * 2^x + 5 in the xy-plane?

A) (0, 3)

B) (0, 5)

C) (0, 8)

D) (0, 11)

**Hint / Guided Steps:**
1. Recall that the y-intercept of a graph occurs where the x-coordinate is 0.
2. Substitute `x = 0` into the function equation: `f(0) = 3 * 2^0 + 5`.
3. Recall that any non-zero number raised to the power of 0 is 1: `2^0 = 1`.
4. Simplify the expression: `3 * (1) + 5`.
5. Write the intercept as a coordinate point `(0, y)`.

### Question 4
**Difficulty:** Medium

If the quadratic function f(x) = x^2 - 6x + c, where c is a constant, has exactly one x-intercept in the xy-plane, what is the value of c?

A) -9

B) 3

C) 6

D) 9

**Hint / Guided Steps:**
1. Recall that a quadratic function `ax^2 + bx + c = 0` has exactly one real solution (meaning one x-intercept) if its discriminant `b^2 - 4ac` is equal to 0.
2. Identify the coefficients: `a = 1`, `b = -6`, and `c` is the constant.
3. Set up the discriminant equation: `(-6)^2 - 4(1)(c) = 0`.
4. Simplify the equation: `36 - 4c = 0`.
5. Solve for `c`.

### Question 5
**Difficulty:** Medium

If f(x) = 2x - 5, which of the following is the expression for the inverse function f^(-1)(x)?

A) f^(-1)(x) = (x + 5) / 2

B) f^(-1)(x) = (x - 5) / 2

C) f^(-1)(x) = 2x + 5

D) f^(-1)(x) = 0.5x - 5

**Hint / Guided Steps:**
1. Set the function equal to `y`: `y = 2x - 5`.
2. Swap the positions of `x` and `y` to find the inverse relationship: `x = 2y - 5`.
3. Solve the new equation for `y`. First, add 5 to both sides: `x + 5 = 2y`.
4. Divide both sides by 2 to isolate `y`.
5. The resulting expression represents the inverse function `f^(-1)(x)`.

### Question 6
**Difficulty:** Medium

The piecewise function f(x) is defined below. What is the value of f(-3) + f(3)?
f(x) = x^2 - 4, for x >= 0
f(x) = 2x - 4, for x < 0

A) -5

B) -1

C) 1

D) 5

**Hint / Guided Steps:**
1. Evaluate `f(-3)` first. Look at the domain conditions: since `-3 < 0`, use the second piece of the function: `f(-3) = 2(-3) - 4`. Calculate the result.
2. Evaluate `f(3)` next. Look at the domain conditions: since `3 >= 0`, use the first piece of the function: `f(3) = 3^2 - 4`. Calculate the result.
3. Add the two calculated values together.

### Question 7
**Difficulty:** Medium

The graph of y = f(x) has a maximum point at (2, 8). What is the coordinates of the maximum point of the graph of y = f(x - 3) + 5?

A) (-1, 13)

B) (5, 3)

C) (5, 13)

D) (-1, 3)

**Hint / Guided Steps:**
1. Analyze the transformations applied to the function `f(x)` to get `f(x - 3) + 5`:
   - The term `(x - 3)` shifts the graph horizontally 3 units to the right. This adds 3 to the x-coordinate of every point.
   - The term `+ 5` shifts the graph vertically 5 units up. This adds 5 to the y-coordinate of every point.
2. Apply these shifts to the coordinates of the original maximum point `(2, 8)`:
   - New x-coordinate: `2 + 3`.
   - New y-coordinate: `8 + 5`.
3. Write down the new coordinate point.

### Question 8
**Difficulty:** Hard

For the functions f and g, f(x) = 3x - 1 and f(g(x)) = 6x + 5. Which of the following is the expression for g(x)?

A) g(x) = 2x + 2

B) g(x) = 2x + 6

C) g(x) = 18x + 14

D) g(x) = 18x + 15

**Hint / Guided Steps:**
1. Write the expression for the composite function `f(g(x))` by substituting `g(x)` into the equation of `f(x)` in place of x: `f(g(x)) = 3 * g(x) - 1`.
2. Set this expression equal to the given value of `f(g(x))`: `3 * g(x) - 1 = 6x + 5`.
3. Solve the equation for `g(x)`. Add 1 to both sides: `3 * g(x) = 6x + 6`.
4. Divide the entire equation by 3 to isolate `g(x)`.

### Question 9
**Difficulty:** Hard

A function f(x) satisfies the relation f(x + y) = f(x) * f(y) for all real numbers x and y. If f(1) = 3, what is the value of f(4)?

A) 12

B) 27

C) 81

D) 243

**Hint / Guided Steps:**
1. Use the relation `f(x + y) = f(x) * f(y)` recursively:
   - To find `f(2)`, write it as `f(1 + 1)`: `f(2) = f(1) * f(1)`. Calculate `3 * 3`.
   - To find `f(3)`, write it as `f(2 + 1)`: `f(3) = f(2) * f(1)`. Multiply the value of `f(2)` by `f(1)`.
   - To find `f(4)`, write it as `f(3 + 1)`: `f(4) = f(3) * f(1)` (or `f(2) * f(2)`).
2. Calculate the final value.

### Question 10
**Difficulty:** Hard

The function f(x) = (x - a)(x - b) has x-intercepts at (2, 0) and (6, 0). If the vertex of the parabola is at (h, k), what is the value of k?

A) -4

B) -2

C) 2

D) 4

**Hint / Guided Steps:**
1. Identify the roots `a` and `b` of the function from the x-intercepts: `a = 2` and `b = 6`. The equation is `f(x) = (x - 2)(x - 6)`.
2. Recall that the x-coordinate of the vertex `h` lies exactly halfway between the two x-intercepts.
3. Calculate `h` by finding the average of 2 and 6: `h = (2 + 6) / 2 = 4`.
4. Find the y-coordinate of the vertex `k` by evaluating the function at `x = h`: `k = f(4)`.
5. Substitute 4 into the function: `k = (4 - 2)(4 - 6)`.
6. Calculate the multiplications to find `k`.
